# Estados comuns de Minha Participação

| Estado apresentado | Uso nesta fundação |
| --- | --- |
| Rascunho | transitório antes do protocolo |
| Guardado | Relata `captured_private` |
| Precisa de informação | `action_required` sanitizado |
| Acompanhando | protocolo legado/caso coletivo |
| Ainda não encaminhado | Relato sem envio institucional |
| Retirado / Arquivado | item inativo, com histórico preservado |
| Protocolo oficial recebido | seção vazia preparada, sem simular envio |

Os domínios mapeiam estados físicos para esta apresentação; miniapps não criam rótulos equivalentes paralelos.
