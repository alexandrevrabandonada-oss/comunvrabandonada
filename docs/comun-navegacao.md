# Navegação

Navegação pública principal: Início, Pautas, Territórios, Participar, Rádio e Acervo. Busca é uma ação global. Minha Participação, Caixa de Entrada e Conta formam a área pessoal.

No celular a barra fixa contém no máximo cinco destinos. Breadcrumbs aparecem nas páginas de contexto. Links complementares — mapa, observatórios, resultados, arte e segurança — ficam no rodapé para evitar um menu infinito.
