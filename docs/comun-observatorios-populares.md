# Observatórios Populares

Motor comum ligado a pauta, projeto e território. O fluxo é observação pendente → validação humana → agregação segura → snapshot em revisão → publicação editorial → evidência/ação. Transporte é a primeira especialização, não uma aplicação paralela.

Entidades: observatório; metodologia e formulário versionados; observação; entidade monitorada; eventos de verificação; definição de métrica; snapshot; relatório e vínculo com ação. Alterações de cálculo geram metodologia nova e resultados históricos preservam sua versão.
