# Modo de campo

`/comun/observatorios/[slug]/campo/[campaignSlug]` requer sessão ativa de admin/editor. Ele cria observação privada `pending`, recalcula espera/atraso no servidor e registra flags de consistência; não aceita publicação automática.

Não registrar nome de passageiro, motorista, contato, trajetória pessoal ou localização contínua.
