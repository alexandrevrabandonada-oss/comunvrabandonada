# Rádio Comunitária do COMUN

A rádio é um acervo sonoro sob demanda ligado a pautas e territórios. Programas agrupam episódios permanentes; não há feed infinito, ranking, autoplay nem transmissão ao vivo real.

Fluxo local: original privado → consentimentos e direitos → FFprobe/FFmpeg local → derivada MP3 e waveform públicos → revisão humana → publicação manual. Contribuições sempre começam como `pending`.

Comandos: `npm run local:env:check`, `npm run local:radio:start`, `npm run local:radio:test` e `npm run smoke:community-radio`.
