# Transcrição de História Oral

Versões são imutáveis e correções criam novo número. `internal_full` nunca aparece publicamente; somente versões públicas aprovadas podem ser selecionadas.

O provider atual é manual. A abstração prepara integração futura, mas nenhum áudio é enviado a terceiros e transcrição automática não é obrigatória.
# Trabalho manual do piloto

O painel `/comun/admin/acervo/historias-orais/transcricoes/trabalho` registra progresso aproximado, tempo, revisões e as decisões separadas de fidelidade e risco. Essas métricas não servem para ranking individual.
