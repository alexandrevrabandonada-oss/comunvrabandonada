# Campanhas de observação

Uma campanha coordena plano, turnos, equipe, observações, revisão, cobertura e relatório. Ela não substitui o observatório: sempre aponta para uma metodologia e um formulário versionados.

Estados: `draft`, `planning`, `ready`, `in_field`, `review`, `completed` e `archived`. Só campanhas concluídas com `report_after_approval` podem exibir relatório público publicado.
