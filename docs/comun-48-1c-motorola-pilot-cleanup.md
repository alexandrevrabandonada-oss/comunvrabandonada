# COMUN 48.1C — checklist de soft cleanup

Status: **PREPARED — NO HUMAN SESSIONS YET**.

Aplicar imediatamente após cada jornada sintética, no mesmo navegador e
contexto da sessão. Não copiar protocolo, receipt, UUID ou conteúdo para a nota
de observação. Nunca usar hard delete.

## Antes de limpar

- [ ] Confirmar que a ocorrência era sintética.
- [ ] Se houver dúvida ou ocorrência real, parar e perguntar à pessoa se deseja
      manter o registro; não tratar relato real como fixture.
- [ ] Confirmar que nenhum canal institucional foi aberto e que não houve
      declaração de envio.

## Soft cleanup sintético

- [ ] Retirar o Relata pela ação existente da pessoa.
- [ ] Confirmar retirada lógica da foto, se usada.
- [ ] Confirmar retirada lógica da localização privada, se usada.
- [ ] Retirar o adapter especializado de Calçadas, quando aplicável.
- [ ] Arquivar o item em Meus registros/Carteira.
- [ ] Confirmar zero package e zero attempt ativo.
- [ ] Não excluir linhas, objetos ou eventos de auditoria fisicamente.

## Post-check obrigatório

- [ ] zero publicação ou snapshot público;
- [ ] zero coletivo;
- [ ] zero forwarding `sent`;
- [ ] zero request externo;
- [ ] zero package/attempt ativo;
- [ ] zero hard delete.

Se o cleanup não puder ser comprovado, interromper novas sessões sintéticas e
registrar um finding de segurança/recuperação sem incluir identificadores ou
conteúdo privado.
