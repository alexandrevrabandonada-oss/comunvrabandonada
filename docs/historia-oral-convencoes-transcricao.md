# Convenções de transcrição

- pausa relevante: `[pausa]`; inaudível: `[inaudível 00:12]`; interrupção: `[interrupção]`;
- riso/emoção somente quando editorialmente relevante: `[risos]`, `[emociona-se]`;
- anonimização: `[nome removido]`; corte relevante: `[…]` com nota editorial pública;
- correção não silenciosa: `[sic]` quando indispensável; preservar linguagem oral sem caricatura;
- nome incerto: `[nome incerto]`; trecho removido: `[trecho retirado por privacidade/consentimento]`.

Fidelidade é comparada com o áudio; risco revisa identificação, terceiros, dados sensíveis e contexto. Fonte externa automatizada não é permitida no piloto.
